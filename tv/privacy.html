개인정보 처리방침

시니어 IT 도우미 GPT · 최종 업데이트 2026-08-15

"시니어 IT 도우미" ChatGPT Custom GPT(이하 "본 GPT")는 AI독학꿀벌 채널이 어르신·왕초보를 위해 무료로 제공하는 도우미입니다. 본 GPT 가 사용자의 어떤 정보를 어떻게 처리하는지 아래에 정리했습니다.

1. 본 GPT 가 직접 수집하는 정보

없습니다. 로그인·회원가입 절차가 없으며 이름·이메일·전화번호 등 개인식별정보를 요구하지 않습니다.

2. 처리되는 정보

사용자가 본 GPT 에게 보내는 질문 텍스트와 업로드한 이미지는 아래 흐름으로 처리됩니다:

  • ChatGPT 플랫폼(OpenAI)이 대화를 받아 처리 — OpenAI 개인정보 처리방침 적용
  • 질문 텍스트는 관련 강의 검색을 위해 채널 운영자의 백엔드 서버(Supabase Edge Function)로 전달됨
  • 백엔드 서버는 질문을 벡터 임베딩으로 변환 후 채널 강의 자료 DB 에서 유사한 조각을 검색
  • 검색 결과(강의 조각 · 유튜브 링크)만 다시 ChatGPT 에 반환됨
본 GPT 운영자의 서버에는 질문 원문이 저장되지 않습니다. 검색 요청 로그(질문 텍스트 포함)가 최대 7일간 임시 보관될 수 있으며, 이는 서비스 오류 진단 목적에만 사용된 후 자동 삭제됩니다.

3. 제3자 제공

본 GPT 는 사용자 정보를 광고·마케팅 목적의 제3자에게 제공하지 않습니다. 다만 아래 서비스가 질문 처리 과정에 기술적으로 관여합니다:

  • OpenAI — ChatGPT 대화 처리 및 질문 임베딩 계산
  • Supabase — 강의 자료 검색용 벡터 데이터베이스 호스팅 (서울 리전)
  • YouTube — 관련 강의 링크 클릭 시 YouTube 로 이동

4. 저장되는 데이터의 범위

본 GPT 운영자가 사전에 인덱싱하여 검색 대상 DB 에 저장한 자료는 아래로 한정됩니다:

  • AI독학꿀벌 채널의 공개 유튜브 영상 자막(공개된 정보)
  • 채널 운영자의 강의 기획·스크립트 문서

홍보 자료·이메일 연락처·개인정보 포함 문서는 인덱싱 대상에서 원천 제외되며, 저장 전 자동 필터(이메일·전화번호·주민등록번호·신용카드·API 키 정규식 스캔)를 거칩니다.

5. 사용자 권리

본 GPT 는 사용자 계정을 만들지 않으므로 삭제·정정할 사용자 정보 자체가 존재하지 않습니다. 사용자와 ChatGPT 사이의 대화 기록은 사용자의 ChatGPT 계정에서 직접 관리할 수 있습니다.
